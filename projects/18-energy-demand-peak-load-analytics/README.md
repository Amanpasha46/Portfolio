# Energy Demand & Peak Load Analytics

Analyze hourly electricity demand to understand peak-load behavior, seasonality, operational drivers, and short-term demand patterns.

## Business Questions
- When does electricity demand peak?
- How do hour, weekday, month, and temperature affect demand?
- Which periods create operational peak-load risk?
- How accurately can near-term demand be forecast?
- What actions could help reduce peak-load pressure?

## Implementation Plan
1. Load and validate hourly demand data.
2. Clean timestamps, missing values, and duplicates.
3. Explore hourly, daily, weekly, and seasonal patterns.
4. Engineer calendar, lag, and rolling-window features.
5. Build a baseline forecast.
6. Compare forecasting approaches using MAE, RMSE, and MAPE.
7. Analyze peak-load periods and contributing factors.
8. Prepare a Power BI dashboard.

## Tools
Python, Pandas, NumPy, Matplotlib, scikit-learn, SQL, Power BI

## Portfolio Value
Demonstrates time-series reasoning, forecasting, feature engineering, SQL analysis, KPI design, and business interpretation without fabricated results.
