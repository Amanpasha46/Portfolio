# Data

Place the local e-commerce dataset here using these logical tables/fields:

- `orders`: order_id, customer_id, product_id, order_date, quantity, unit_price
- `customers`: customer_id, customer_name, region
- `products`: product_id, product_name, category

Recommended source: a public e-commerce/sales dataset from Kaggle or another reputable open-data source. Record the exact dataset URL, license, and download date here before publishing the finished project.

For privacy and repository size, do not commit real customer PII or large raw files. If the dataset is public and small enough to distribute, verify its license before committing it.
