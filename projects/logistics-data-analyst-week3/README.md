# Week 3 – Advanced Data Analysis and Visualization in Logistics

This project is part of the YuvaIntern Logistics Data Analyst Internship.

## Objective
Explore a hypothetical logistics dataset using Python, perform exploratory data analysis (EDA), create meaningful visualizations, and interpret logistics performance.

## Dataset
A simulated dataset of 1,200 shipment records with:
- Shipment volume
- Route distance
- Travel and delivery time
- Promised delivery time
- Delivery delay
- Transportation cost
- Cost per shipment
- Destination zone
- Vehicle type
- On-time delivery status

The dataset is hypothetical and is used only for demonstrating the internship analysis workflow.

## Analysis
The Python script performs:
1. Dataset simulation
2. Descriptive statistics
3. Distribution analysis
4. Daily shipment-volume trend analysis
5. Cost vs. distance relationship analysis
6. Correlation analysis
7. Destination-zone comparison
8. Vehicle-type on-time comparison
9. Export of the simulated dataset

## Visualizations
- Delivery time distribution
- Daily shipment volume trend
- Transportation cost vs. route distance
- Correlation matrix
- Average delivery time by destination zone
- On-time delivery rate by vehicle type

## Tools
Python, NumPy, pandas, and Matplotlib.

## Files
- `week3_logistics_analysis.py` – analysis and visualization script
- `requirements.txt` – Python dependencies

Run:
```bash
pip install -r requirements.txt
python week3_logistics_analysis.py
```

The report contains the detailed methodology, charts, interpretations, insights, bottlenecks, and recommendations.
