# Data

Do not commit large raw datasets to GitHub.

Suggested sources:
- A city open-data portal with transit stops and neighborhood boundaries.
- A public GTFS feed containing stops.txt.
- Census or municipal population data at neighborhood/tract level.

Save raw files locally under `data/raw/` and generated tables under `data/processed/`.
Document the exact source URL, download date, coordinate system, and license in the notebook before publishing results.
