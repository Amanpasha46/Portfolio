# Findings Template

Use this file after running the analysis.

## Dataset
Record source, date accessed, license, row count, and available fields.

## Data Quality
Document missing values, duplicates, invalid timestamps, and amount anomalies.

## Key Patterns
Summarize transaction behavior by amount, time, location, device, and account where available.

## Model Results
Report the Isolation Forest configuration and evaluation metrics that are actually produced. Do not invent results.

## Investigation Priorities
Explain how alert thresholds and priority bands were selected.

## Limitations
Anomaly detection can flag legitimate unusual behavior. Results depend on the dataset, features, contamination assumptions, and threshold selection.
