# Power BI Dashboard

Recommended pages:

1. **Pricing Overview** — revenue, units, average price, and category trends.
2. **Elasticity** — estimated elasticity by product/category with sample-size context.
3. **Scenario Simulator** — compare baseline and alternative-price revenue assumptions.
4. **Decision Support** — products requiring deeper pricing tests and supporting evidence.

Do not present modeled scenario revenue as an observed result. Clearly label assumptions and model-based estimates.
