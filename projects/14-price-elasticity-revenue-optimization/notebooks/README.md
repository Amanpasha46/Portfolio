# Analysis Notebook

Create `01_price_elasticity_analysis.ipynb` using this workflow:

1. Load and inspect the dataset.
2. Validate dates, prices, quantities, and duplicates.
3. Explore price-demand relationships.
4. Aggregate to product-period level.
5. Estimate log-log elasticity.
6. Inspect diagnostics and influential observations.
7. Run price scenarios.
8. Export tables for Power BI.
9. Summarize evidence and limitations.
